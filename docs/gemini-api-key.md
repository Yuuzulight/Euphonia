# Getting a free Gemini API key

Euphonia already writes a short, honest insight for every take with no
setup at all — this key is entirely optional and only used to swap that
for a richer, more personalized version written by Gemini. It's never
sent anywhere except Google's Gemini API, and it's stored encrypted on
your own machine.

1. Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Sign in with a Google account.
3. Click **Create API key**.
4. Copy the key and paste it into Euphonia's Settings screen (the ⚙️
   button), any time.

Gemini's free tier is rate-limited but plenty for occasional personal use.
Nothing in the app requires this — everything, including the default
insight, works fully without it.
